# Tempo restante do Batch 2

Previsão de quanto falta para fechar o Batch 2 do TCC, refeita a partir do ledger do batch toda vez
que a página abre, a cada minuto e no botão "Atualizar agora". Mostra o fim previsto com a faixa
entre o cenário rápido e o lento, o que está em andamento, o que espera uma decisão ou o ok de uma
rodada, a linha do tempo dos itens e como a previsão mudou ao longo do dia.
